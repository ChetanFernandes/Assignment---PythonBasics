# Assignment - Python Basics

This repository contains Jupyter notebooks covering basic Python concepts and variable usage.

## Installation

1. Clone the repository:

   git clone https://github.com/ChetanFernandes/Assignment---PythonBasics.git
   cd Assignment---PythonBasics

2. (Optional) Create and activate a virtual environment:

   python -m venv venv
   source venv/bin/activate  # macOS/Linux
   venv\Scripts\activate    # Windows

3. Install dependencies (if any). The notebooks use standard Python libraries; no external packages are required by default.

## Usage

Open the Jupyter notebooks and run the cells:

   jupyter notebook

Then open either `18_Sep_Python Basics Variable.ipynb` or `9_Sep_Python Basics Variable.ipynb` and run.
